# Metrics that matter

Tracked from day one. Everything else is vanity.

| Metric | Why it matters | Target direction |
| --- | --- | --- |
| Listings live, beds live | The launch gate: 25+ PGs and 500+ beds in one area before seeker traffic | Up, in ONE area |
| % of beds updated in last 24h | Whether inventory is actually real-time | Above 80% |
| Owners using the register weekly | Predicts every other number; it is why availability stays true | Up |
| Search → listing view → visit booked → visited → moved in | Where the funnel leaks | Each step measured separately |
| False availability incidents per 100 bookings | The trust killer | Trending to zero |
| Move-ins per week | The only revenue event | Up |
| Collection rate on owner invoices | Whether the business model works at all | Above 70% |

## The launch gate

Do not send a single seeker until one area has 25+ PGs and 500+ beds live with photos. A search that returns four results kills the app's reputation in that locality permanently, and you only get one launch per area.
