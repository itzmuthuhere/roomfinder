# RoomFinder docs kit — how to use

Copy these into your repo root:

```
roomfinder/
├── CLAUDE.md                      <- the rules file (sent separately)
├── mkdocs.yml
├── .github/workflows/docs.yml           <- builds + publishes the docs site
├── .github/workflows/docs-required.yml  <- fails PRs that change code without docs
├── .claude/commands/ship-feature.md     <- /ship-feature
├── .claude/commands/document-feature.md <- /document-feature
├── docs/...                       <- the documentation site content
├── api/                           <- Spring Boot
└── app/                           <- React
```

Then:

1. `pip install mkdocs-material` and run `mkdocs serve` to preview at localhost:8000.
2. In GitHub → Settings → Pages, set Source = GitHub Actions. The first push to main publishes the site.
3. Add springdoc to the Spring Boot build so `generateOpenApiDocs` writes `docs/api/openapi.json`.
4. Keep `docs/schema/` generated by tbls in CI. Never hand-edit it.
5. Add branch protection on `main` requiring the `docs-required` and test checks to pass.

Daily loop in Claude Code: `/ship-feature <feature name>` → review the diff → `/document-feature` → PR → merge → docs deploy automatically.
